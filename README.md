# Will's Election Polls and Predictions

**Independent analysis of the 2026 U.S. elections** — interactive Senate election forecasts, polling comparisons, a governor polling map, and research into historical polling errors.

**Website:** [willelectionpolls.com](https://willelectionpolls.com/)

- [2026 Governor Polling Map](https://willelectionpolls.com/governor.html) — governor race polling and projections

## About the project

The goal is to put forecasts, political context, and polling history in one accessible place where readers can evaluate the evidence for themselves. State-by-state predictions are independent analytical judgments. They are not official results, scientific polling conducted by this project, or guarantees about election outcomes.

The website is updated as election information evolves. For the latest race calls, visit the **interactive site** rather than relying on a screenshot or a static summary.
