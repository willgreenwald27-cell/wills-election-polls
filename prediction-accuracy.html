How we will measure forecast accuracy

Mean absolute error

For every race with a verified final margin, take the absolute difference between the predicted Democratic-minus-Republican margin and the actual margin, then average. Report sample size and excluded races.

Winner accuracy

Count correct winner predictions among races officially called or certified. An unresolved race is excluded, not scored as a loss.

Polling error analysis

Compare final pre-election polling averages with the final reported margins using the same signed-margin convention for every race.

Transparency standard

Snapshot based on the final predictions supplied on November 3, 2026. Original values must never be overwritten by revised projections after polls close.
